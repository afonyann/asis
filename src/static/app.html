🧠 Нейронка (Groq API Key)
Бот работает через Groq (бесплатная нейросеть Llama 3.3 70B).
Вставь свой API-ключ, чтобы бот начал отвечать.
Где взять ключ бесплатно?
1. Зайди на console.groq.com
2. Зарегистрируйся (Google / GitHub — бесплатно)
3. Слева в меню нажми API Keys
4. Нажми Create API Key, дай любое имя
5. Скопируй ключ (начинается с gsk_) и вставь сюда

Лимит бесплатного плана: ~30 запросов/мин, 14 400/день — этого хватит с запасом.
